## 📖 نظرة عامة على المشروع (Overview)

تطبيق ويب تقدمي (**PWA**) تم تصميمه وهندسته بالكامل لتسجيل ومتابعة حضور وغياب الطلاب في المحاضرات الجامعية والمدرجات بأعلى كفاءة وسرعة. 

يعمل التطبيق وفق معيار **Offline-First**؛ أي أنه يعمل بكامل مميزاته **بدون اتصال بالإنترنت نهائياً (أوفلاين 100%)** داخل المدرج، مع إمكانية المزامنة اللحظية على سحابة **Google Cloud Firestore** بمجرد توفر الاتصال. يتميز التطبيق بواجهة مستخدم زجاجية داكنة (**Dark Glassmorphism**) شيك ومريحة للعين ومصممة باللغة العربية بالكامل (**RTL**).

## ✨ المميزات والخصائص الهندسية

### 1. 🎛️ شاشة البداية والتوجيه (Landing & Role Selection)
* **تصميم زجاجي داكن (Dark Glassmorphism):** تأثيرات بلورية عصرية، توهجات نيون مريحة للعين، وأزرار تفاعلية سلسة.
* **الدخول كطالب (Student):** توجيه الطالب فورياً لتسجيل بياناته (لأول مرة) أو فتح بطاقته الذكية إذا كان مسجلاً مسبقاً.
* **الدخول كمحاضر (Instructor):** محمي برمز سري (**PIN Code**) افتراضي: `1234` لمنع تلاعب الطلاب بفتح الكاميرا أو مسح الغياب.
* **مؤشر سحابة المزامنة اللحظي:** يوضح حالة الاتصال (سحابة خضراء: متزامن ومأمن / برتقالية: جاري المزامنة / رمادية: أوفلاين حفظ محلي).

---

### 2. 🎓 مسار الطالب والبطاقة الذكية (Student Flow & QR Card)
* **تسجيل لمرة واحدة فقط:** تُحفظ البيانات بشكل دائم على موبايل الطالب عبر `LocalStorage` و `IndexedDB` لتظل معه طوال الترم.
* **التحقق الصارم من الاسم:** يقبل الحروف العربية فقط ويمنع الأرقام والرموز والإنجليزي، ويشترط مسافتين على الأقل لضمان كتابة الاسم ثلاثي.
* **الرقم القومي (14 رقماً):** إدخال 14 رقماً بالضبط مع **تحويل تلقائي وفوري للأرقام العربية (`٠١٢٣٤٥٦٧٨٩`) إلى أرقام إنجليزية (`0123456789`)**.
* **الأقسام الأربعة الثابتة:** قائمة اختيارات مغلقة تضم: **(آلات - نظم - ري - عام)** لمنع أخطاء الكتابة.
* **بطاقة الحضور والـ QR Code:**
  * توليد كود QR عالي الجودة بحمولة JSON مضغوطة: `{"nid":"...","name":"...","dept":"..."}`.
  * الكود موضوع داخل إطار أبيض عالي التباين لضمان سرعة مسحه بالكاميرا حتى في الإضاءة الخافتة.
  * **زر حفظ الكود كصورة:** يقوم برسم وتنزيل بطاقة الـ QR كصورة `PNG` عالية الدقة في معرض الصور (Gallery) بالموبايل للرجوع إليها بدون نت.

---

### 3. 👨‍🏫 مسار المحاضر وأخذ الغياب (Instructor Flow)
* **يعمل أوفلاين 100%:** لا يشترط وجود نت في قاعة المحاضرات.
* **إدارة المحاضرات (Session Manager):** بدء محاضرة جديدة باسم المادة ورقمها، مع تحديد القسم المستهدف (الكل / آلات / نظم / ري / عام) وتوثيق الوقت والتاريخ تلقائياً.
* **ماسح الـ QR الذكي (Offline Camera Scanner):**
  * فك شفرة الكود محلياً في أجزاء من الثانية من بيانات الكود نفسه.
  * **تأكيد صوتي وحركي مزدوج:** صوت نغمة **Beep** إلكترونية مميزة مُخلقة عبر `Web Audio API` + اهتزاز حركي (**Haptic Vibration**).
  * **منع التكرار الآلي:** في حال مرور نفس الطالب مرتين، يظهر تنبيه تحذيري برتقالي: `"تم تسجيل الطالب مسبقاً"` دون احتساب الحضور مرتين.
* **العداد اللحظي والتوزيع:**
  * عداد رقمي كبير لإجمالي الحضور الفعلي الآن.
  * بطاقات إحصائية لحظية لكل قسم: (**آلات: X** | **نظم: Y** | **ري: Z** | **عام: W**).
* **الإضافة اليدوية (Manual Entry):** نافذة لإدخال بيانات طالب يدوياً بالرقم القومي والاسم والقسم في حال نفاذ شحن بطاريته داخل المدرج.
* **بحث وفلترة فورية:** شريط بحث سريع في جدول الحضور بالاسم أو الرقم القومي أو القسم.

---

### 4. 📊 استخراج شيت الإكسيل على الهاتف (Offline Excel Generator)
* بنقرة واحدة على زر **"تصدير شيت Excel"** ومن داخل المدرج وبدون نت.
* مكتبة `SheetJS (XLSX)` المدمجة تقوم ببناء ملف `.xlsx` منسق فورياً في متصفح الموبايل وتنزيله في مجلد `Downloads`.
* اسم الملف يتولد تلقائياً: `حضور_{اسم_المحاضرة}_{التاريخ}.xlsx`.
* الأعمدة المخرجة:
  1. **م** (الرقم التسلسلي)
  2. **الاسم ثلاثي**
  3. **الرقم القومي** (كنص للحفاظ على الأصفار الأولى)
  4. **القسم**
  5. **وقت الحضور**
  6. **حالة المزامنة** (سحابي / محلي)

---

### 5. ☁️ هيكلة قواعد البيانات والمزامنة (Dual-Database Architecture)
1. **قاعدة البيانات المحلية على الهاتف (`IndexedDB`):** تحفظ سجلات الغياب والطلاب والجلسات محلياً مع وسوم حالة المزامنة.
2. **سحابة جوجل المركزية (`Google Cloud Firestore`):**
   * جدول `students`: يحفظ بيانات الطلاب المسجلين بالرقم القومي.
   * جدول `lectures`: يحفظ جلسات المحاضرات.
   * جدول `attendance`: يحفظ سجلات الغياب اللحظية.
3. **مراقبة الشبكة التلقائية (`Background Sync`):** عند التقاط أي شبكة إنترنت، يرفع التطبيق السجلات غير المتزامنة دفعة واحدة للسحابة مع إضاءة السحابة الخضراء.

## 🛠️ التقنيات المستخدمة (Tech Stack)

| المجال | التقنية | الاستخدام |
| :--- | :--- | :--- |
| **Frontend** | Vanilla JS (ES6+), HTML5, CSS3 | هيكل الواجهة بدون تعقيد الفريم ووركس |
| **Design** | Dark Mode & Glassmorphism | تصميم زجاجي داكن وتأثيرات توهج نيون |
| **PWA** | Service Worker, Manifest JSON | دعم التثبيت على الموبايل والعمل بدون إنترنت |
| **QR Engine** | Kazuhiko Arase QR Generator | توليد أكواد الـ QR عالية الدقة محلياً |
| **Scanner** | Html5-QRCode (ZXing) | قراءة الأكواد عبر كاميرا الموبايل بدون إنترنت |
| **Excel Export** | SheetJS (xlsx.full.js) | بناء وتحميل ملفات الإكسيل داخل المتصفح أوفلاين |
| **Cloud & DB** | Google Cloud Firestore | قاعدة بيانات سحابية لحظية متزامنة |
| **Hosting** | Google Firebase Hosting | استضافة سريعة مشفرة بـ SSL و Google CDN |
| **Local Server** | Node.js + Express + SQLite3 | خادم محلي اختياري ودعم قواعد بيانات SQLite |

## 📁 هيكلية ملفات المشروع (Directory Structure)

```text
smart-attendance/
├── public/
│   ├── index.html           # الصفحة الرئيسية الزجاجية الأحادية (SPA)
│   ├── manifest.json        # ملف تعريف تطبيق الويب التقدمي (PWA)
│   ├── sw.js                # الـ Service Worker لتخزين الموارد والعمل أوفلاين
│   ├── css/
│   │   └── style.css        # التنسيقات الزجاجية الداكنة وتأثيرات النيون
│   ├── js/
│   │   ├── app.js           # المتحكم الرئيسي، إدارة التوجيه، والتحقق
│   │   ├── db.js            # محرك IndexedDB المحلي على الهاتف
│   │   ├── sync.js          # نظام مراقبة الشبكة والمزامنة التلقائية
│   │   ├── qr-scanner.js    # تحكم الكاميرا ومولد نغمات الصوت والاهتزاز
│   │   ├── excel.js         # محرك تصدير شيتات الإكسيل (SheetJS)
│   │   └── firebase-app.js  # كود الربط السحابي مع Google Cloud Firestore
│   ├── libs/                # مكتبات مدمجة محلياً (لا تحتاج نت إطلاقاً)
│   │   ├── html5-qrcode.min.js
│   │   ├── qrcode.js
│   │   └── xlsx.full.min.js
│   └── icons/               # أيقونات التطبيق بدقة عالية (SVG & PNG)
├── server/
│   ├── index.js             # خادم Express المحلي ومسارات الـ API
│   └── database.js          # مخطط ومحرك SQLite3
├── firebase.json            # إعدادات استضافة Google Firebase Hosting
├── firestore.rules          # قواعد أمان قاعدة بيانات Firestore
├── deploy-firebase.bat      # سكريبت النشر التلقائي بضغطة زر واحدة
├── start.bat                # سكريبت التشغيل المحلي مع Cloudflare Tunnel
└── package.json             # تعريف المشروع والتبعيات
```

## 📱 التثبيت على الموبايل (PWA Installation)
1. افتح الرابط: **[https://smart-attendance-7019f.web.app](https://smart-attendance-7019f.web.app)** في متصفح موبايلك (Chrome أو Safari).
2. اضغط على خيارات المتصفح (⋮) ثم اختر:
   * على أندرويد: **"تثبيت التطبيق"** أو **"Add to Home screen"**.
   * على آيفون: اضغط زر المشاركة (Share) ثم **"Add to Home Screen"**.
3. سيظهر التطبيق على شاشة موبايلك الرئيسية بأيقونته الرسمية ويعمل فورياً كتطبيق هاتف أصلي بدون شريط المتصفح وبدون إنترنت!
