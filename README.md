# نظام الحضور والغياب الذكي (Smart Attendance PWA)

تطبيق ويب تقدمي (Progressive Web App - PWA) لتسجيل الحضور والغياب للطلاب والمحاضرين بالـ QR Code يعمل **أوفلاين 100% وأونلاين**، بواجهة مستخدم زجاجية داكنة (Dark Glassmorphism) متوافقة مع متصفحات الهواتف والحواسب.

---

## 🚀 المميزات الرئيسية

### 1. شاشة البداية والتوجيه (Landing & Role Selection)
- تصميم زجاجي داكن (Dark Glassmorphism) مريح للعين مع تأثيرات توهج نيون.
- مسار مخصص للطلاب ومسار محمي برمز سري للمحاضر لمنع تلاعب الطلاب.
- مؤشر حالة الاتصال والمزامنة الذكي (سحابة خضراء / تنبيه المزامنة / وضع العمل أوفلاين).

### 2. مسار الطالب (Student Flow)
- **تسجيل لمرة واحدة فقط:** حفظ فوري على الهاتف (`LocalStorage` + `IndexedDB`).
- **التحقق الدقيق من الاسم:** يقبل الحروف العربية فقط ويشترط اسماً ثلاثياً على الأقل (مسافتان فاصلتان).
- **الرقم القومي:** 14 رقماً بالضبط مع تحويل الأرقام العربية إلى الإنجليزية تلقائياً وتجاهل الحروف.
- **الأقسام الأربعة الثابتة:** (آلات - نظم - ري - عام).
- **بطاقة الـ QR Code الذكية:** كود مضغوط بصيغة JSON داخل حاوية بيضاء متباينة لتسهيل القراءة السريعة.
- **تنزيل الكود كصورة:** زر مخصص لحفظ البطاقة في معرض الصور لاستخدامها بدون نت.

### 3. مسار المحاضر والمسح الذكي (Instructor Flow)
- **حماية برمز سري (PIN Code):** الرمز الافتراضي: `1234` (قابل للتعديل).
- **إدارة المحاضرات:** بدء محاضرة جديدة باسم المادة وتحديد القسم المستهدف مع توثيق التاريخ والوقت تلقائياً.
- **كاميرا المسح السريع الأوفلاين:** تفك شفرة الكود محلياً بدون إنترنت في أجزاء من الثانية.
- **تنبيهات صوتية وحركية:** صوت Beep مميز مُولّد عبر Web Audio API + اهتزاز (Vibration) عند نجاح المسح.
- **منع التكرار التلقائي:** ظهور تنبيه برتقالي فوري "تم تسجيل الطالب مسبقاً" مع نغمة تحذير خاصة.
- **العداد اللحظي:** إجمالي الحضور مع تفصيل فوري لكل قسم (آلات - نظم - ري - عام).
- **الإضافة اليدوية:** إمكانية إدخال بيانات طالب يدوياً في حال نفاذ بطارية هاتفه داخل المدرج.

### 4. تصدير شيت الإكسيل محلياً (Offline Excel Generator)
- تصدير ملف إكسيل `.xlsx` فورياً ومباشرة على الهاتف باستخدام مكتبة `SheetJS` المدمجة محلياً (بدون نت نهائياً).
- الأعمدة: **(م | الاسم ثلاثي | الرقم القومي | القسم | وقت الحضور | حالة المزامنة)**.
- تسمية تلقائية للملف: `حضور_{اسم_المحاضرة}_{التاريخ}.xlsx`.

### 5. نظام المزامنة المزدوج وقاعدة البيانات (Dual-Database & Background Sync)
- **على الهاتف:** قاعدة بيانات `IndexedDB` لحفظ جميع الطلاب والجلسات والغياب محلياً.
- **على السيرفر:** قاعدة بيانات `SQLite` مدعومة بـ Node.js و Express.
- **مزامنة تلقائية:** بمجرد التقاط شبكة واي فاي أو باقة بيانات، يتم رفع السجلات دفعة واحدة للسيرفر دون فقدان أي بيانات.

## 🛠️ كيفية التشغيل

### تشغيل السيرفر محلياً:
```bash
npm start
```

التطبيق سيعمل على:
`http://localhost:3000`

### الفتح من الموبايل داخل نفس شبكة الواي فاي أو الهوتسبوت:
1. افتح الـ Terminal واكتب `ipconfig` لمعرفة عنوان الـ IPv4 الخاص بجهاز الكمبيوتر (مثلاً: `192.168.1.15`).
2. افتح متصفح الموبايل (Chrome أو Safari) واكتب:
   `http://192.168.1.15:3000`
3. يمكنك الضغط على **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)** لتثبيته كتطبيق PWA أصلي يعمل بدون إنترنت!
